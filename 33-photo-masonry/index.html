.masonry {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
    gap: 20px;
}
💡 The Magic Formula:
• auto-fit = as many columns as fit, stretch to fill space
• minmax(250px, 1fr) = each column at least 250px, can grow
• No media queries needed! The browser handles everything.
🔧 How It Works
/* When screen is 500px wide: */ /* 500 ÷ 250 = 2 columns → each gets 250px */ /* When screen is 600px wide: */ /* 600 ÷ 250 = 2 columns → each gets 300px (extra space distributed) */ /* When screen is 750px wide: */ /* 750 ÷ 250 = 3 columns → each gets 250px */ /* When screen is 1000px wide: */ /* 1000 ÷ 250 = 4 columns → each gets 250px */ /* When screen is 1200px wide: */ /* 1200 ÷ 250 = 4 columns → each gets 300px */
📊 auto-fit vs auto-fill
auto-fit collapses empty columns (items stretch).
auto-fill keeps empty columns (reserves space).
/* auto-fit - columns stretch to fill space */
.grid { grid-template-columns: repeat(auto-fit, minmax(200px, 1fr)); }

/* auto-fill - reserves space for empty columns */
.grid { grid-template-columns: repeat(auto-fill, minmax(200px, 1fr)); }
🏆 For photo galleries, use auto-fit — you want images to fill the available space without gaps.
