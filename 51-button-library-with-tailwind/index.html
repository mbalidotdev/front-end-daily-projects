🎨 Button Library

A complete reference of button styles built with Tailwind CSS utilities. Each button is styled entirely with classes — no custom CSS!

class="bg-blue-500 text-white px-4 py-2 rounded-lg hover:bg-blue-700 transition"

🔘 Solid Buttons

Standard buttons with solid background colors.

<button class="bg-blue-500 text-white px-4 py-2 rounded-lg hover:bg-blue-700 transition">Primary</button>

What each class does: bg-blue-500 = background blue, text-white = white text, px-4 = horizontal padding, py-2 = vertical padding, rounded-lg = rounded corners, hover:bg-blue-700 = darker on hover, transition = smooth color change

🔘 Outline Buttons

Buttons with borders and transparent backgrounds.

<button class="border border-blue-500 text-blue-500 px-4 py-2 rounded-lg hover:bg-blue-500 hover:text-white transition">Outline Primary</button>

border border-blue-500 = blue border, hover:bg-blue-500 hover:text-white = fill on hover

📏 Button Sizes

Different padding combinations create different sizes.

Small: px-2 py-1 text-sm
Medium: px-4 py-2
Large: px-6 py-3 text-lg rounded-lg
XL: px-8 py-4 text-xl rounded-xl

🔘 Button Shapes

Different border-radius values create different shapes.

rounded = 4px | rounded-md = 6px | rounded-lg = 8px | rounded-xl = 12px | rounded-full = pill shape

🎯 Buttons with Icons

Using flexbox to align icons with text.

<button class="flex items-center gap-2">
  <span>👍</span> Like
</button>

flex + items-center + gap-2 aligns icon and text horizontally with space between.

⌨️ Focus State (Keyboard Navigation)

Press Tab to navigate to these buttons and see the focus ring.

class="... focus:ring-2 focus:ring-blue-300 focus:outline-none"

focus:ring-2 = 2px ring around button when focused, focus:outline-none = removes default outline (replaced with ring)

🚫 Disabled State

Buttons that are not clickable.

class="... opacity-50 cursor-not-allowed" disabled

Add disabled attribute to the button, plus opacity-50 and cursor-not-allowed for visual feedback.

📱 Full Width Button

Button that takes the full width of its container. Common on mobile forms.

class="... w-full"

w-full makes the button span 100% of its parent container's width.

✨ Animated Buttons

Buttons with subtle animations on hover.

Scale: hover:scale-105 transition-transform duration-200
Lift: hover:-translate-y-1 transition-transform duration-200
Shadow: hover:shadow-lg transition-all duration-200
Text: hover:tracking-wider transition-all duration-200
