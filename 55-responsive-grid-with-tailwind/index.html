📚 Responsive Prefix Reference

Prefix Min Width Target Device Example
(none) 0px Mobile (default) grid-cols-1
sm: 640px Large phone sm:grid-cols-2
md: 768px Tablet md:grid-cols-3
lg: 1024px Desktop lg:grid-cols-4
xl: 1280px Large desktop xl:grid-cols-5
2xl: 1536px Extra large 2xl:grid-cols-6
