Navigation Bars with Tailwind

This page shows 6 different navigation bar styles built entirely with Tailwind CSS. Scroll down to see them all!

class="flex justify-between items-center px-4 py-3 bg-gray-800 text-white"

Each class does ONE thing: flex = display flex, justify-between = space between, items-center = vertical center, px-4 py-3 = padding, bg-gray-800 = dark background, text-white = white text
