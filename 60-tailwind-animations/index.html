📚 Tailwind Animation Classes

Built-in Animations

  • animate-pulse - Fades in and out
  • animate-spin - Rotates continuously
  • animate-bounce - Bounces up and down
  • animate-ping - Ping effect (like notification)

Transition Utilities

  • transition - Enables transitions
  • duration-200 - 200ms duration
  • ease-in-out - Easing function
  • delay-100 - Delay before animation

Transform Utilities

  • scale-105 - Scales up 5%
  • -translate-y-1 - Moves up 4px
  • rotate-3 - Rotates 3 degrees

Transition Properties

  • transition-all - All properties transition
  • transition-colors - Only colors transition
  • transition-transform - Only transforms transition
